# Trung tâm tiếng Anh (TTA) 
## Giới thiệu 
Chào mừng mọi người đến với hệ thống website của TTA. Dự án giúp **tối ưu hóa** quy trình quản lý học viên và *tự động hóa* việc tính toán học phí hằng tháng.
## Cấu trúc thư mục
|`Thư mục` | `Nội dung`
| :---: | :---: |
| `data`| Chứa các file Excel dữ liệu học phí |
| `docs`| Chứa lịch học |
| `archive` | Chứa ảnh logo trung tâm và ảnh lớp học |

## Các quy trình đăng ký học tại TTA
1. Học viên đăng ký thông tin cá nhân và chọn khóa học phù hợp
2. Hệ thống kiểm tra xếp lớp, xếp lịch học và gửi thông báo.
3. Học viên hoàn thiện học phí để kích hoạt tải khoản học.
